# عرض العمليات والقيود

السياسة المعتمدة: بساطة العرض مع إمكانية تتبع كل عملية إلى مصدرها.

- العملية المستقلة لها مرجع مستقل. ملخص مبيعات الفرع في اليوم يجمع قنوات الدفع التابعة له.
- فاتورة المشتريات وسدادها اللاحق عمليتان منفصلتان. التحويل الداخلي يجمع طرفي التحويل تحت مرجع واحد.
- لا تُدمج عمليات لمجرد تشابه المبلغ أو المورد أو وجودها في ملف مرفوع واحد، ولا تُجمع حسب عدد اعتباطي.
- العرض الافتراضي جدول محاسبي واحد: الحساب، البيان المختصر، مدين، دائن. بنود العملية تحت بعضها، والمرجع يظهر مرة واحدة.
- فتح المرجع يعرض الجدول نفسه، والمستندات والتفاصيل الأصلية في قسم يُفتح عند الطلب. الطباعة للجدول دون البطاقات والشروحات.
- ملخص اليوم وسيلة عرض وطباعة، ولا ينشئ قيودًا أو يعيد ترحيل مبالغ.
- الحسابات بالأجزاء الصحيحة من الريال؛ إجماليات الحركة للمعتمد والتلقائي فقط، مع استبعاد الملغى.
- تبويب حركات الحسابات يبقى داخل/خارج. جدول القيود يحول الأثر المسجل إلى مدين/دائن: زيادة الأصول مدينة وزيادة الموردين دائنة، والعكس عند النقص.
- مقابل الشراء/المصروف هو التصنيف المالي المسجل، والضريبة مستقلة عند التسجيل الضريبي؛ غير المسجل تُضم ضريبة الشراء للتكلفة. سداد المورد يخفض المورد ولا يعيد إثبات المشتريات.
- مقابل المبيعات هو المبيعات وضريبتها المسجلة. السجلات القديمة ذات ضريبة مبيعات NULL تستخدم حساب 15% الموجود في المحرك فقط للمنشأة المسجلة، مع وسم «تقديرية» ظاهر؛ الصفر الصريح لا يُستبدل بتقدير.
- هذا عرض محسوب من السجل الحالي، لا ترحيل جديد ولا دليل حسابات أو دفتر أستاذ مزدوج دائم. لا تُملأ التسويات أو القروض غير المصنفة بحساب مقابل مختلق؛ تظهر للمراجعة حتى تُحدد من مصدرها.
- تساوي الطرفين ليس إثباتًا لصحة التصنيف. الحساب البنكي/المورد المفقود، الطرف الناقص، الضريبة غير المحددة أو الحساب المقابل المجهول تُوسم كغير مكتملة حتى لو تساوت الإجماليات.
- التصفية تختار القيد كاملًا بجميع أطرافه. التحميل الناقص يمنع العرض والطباعة؛ البيانات المكتملة تقنيًا ذات تصنيف ناقص تُطبع مع نفس التنبيه الظاهر، لا كقيد مكتمل.
